# Repose planner v9.1

V9.1 is a narrow hardware-evidence patch over v9. It does not change the
autonomous approach gait, distance windows, clip table, belief vote, palette,
or colour rejection threshold.

## Changes

- A valid depth-supported colour vote is authoritative. Projected square RGB
  pooling is used only when the depth vote is absent, so a projection miss can
  no longer turn a clear observation into `no_color`.
- The stillness gate is `0.25 rad/s` (v9: `0.15`) and SETTLE lasts 60 planner
  ticks / 1.2 s (v9: 40 / 0.8 s).
- Plane visibility admission is `0.55` (v9: `0.70`).
- Each fresh global search starts with positive yaw, physically left / CCW.
  Its remaining non-cancelling ladder is unchanged. A valid localization or a
  directed `turn->approach` clears the old global-search phase.
- Manual joystick walk in STAND requests 1.0 m by default. It still executes a
  bounded source clip and returns to stand; autonomous approach remains capped
  by its own `approach.*` settings.

The v9 configs remain installed for direct A/B comparison.
