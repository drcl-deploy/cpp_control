# Repose planner v9.3

V9.3 is the smallest evidence-backed scan-policy delta over v9.2. It retains
localization, colour pooling, approach, clip selection and reference generation
unchanged.

## Evidence

In `bags/04Sep2026_05_25`, both recorded test episodes solved. The unnecessary
search cascade began at `t+222.1 s`: two accepted reads agreed on pink and
carried a cube pose; the third read returned `no_blob`. V9.2 immediately
committed `search 2/3` because total reads had reached `min_votes: 3`, despite
the configured eight-read belief window.

V9.3 separates positive and negative evidence:

- three agreeing, placed reads still act immediately;
- incomplete or disagreeing evidence holds SETTLE until eight accepted reads;
- an identical finished SETTLE remains engaged, so it does not clear those
  accumulating reads merely because its reference clock reached the tail;
- eight reads without a valid placed vote still launch the same bounded scan;
- every completed global-search cycle restarts anticlockwise instead of
  alternating its initial direction.

The joystick-to-POLICY heading tolerance and `omega_still: 0.25` are unchanged.
