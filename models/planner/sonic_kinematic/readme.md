# SONIC kinematic model

Place the GEAR-SONIC V2 planner export here as:

```text
planner_sonic.onnx
```

The ONNX file is distributed in NVIDIA's `nvidia/GEAR-SONIC` Hugging Face
repository. It is a local runtime artifact and is ignored by Git. See
`docs/planners/sonic_kinematic.md` for the exact download and validation steps.
